The Spore name and the logos in this folder are not covered by the MIT
license of the rest of the repository. Copyright (c) 2026 Jimmy Arellano.

You can use them to refer to Spore itself: in an article, a video, a review,
a list of desktops, or a package of Spore that is built from this
repository without changes to what it does.

A modified version (a fork) has to use another name and another logo, so
nobody takes it for Spore.
